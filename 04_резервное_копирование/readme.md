# Задание 4. Резервное копирование проекта

## Сложность

Продвинутая. Готового решения нет: нужно спроектировать последовательность команд самостоятельно и проверить результат.

## Сценарий

В каталоге `webapp` уже находится небольшой учебный проект. В нём есть исходный код, настройки, данные, временные файлы и секретная конфигурация. Начните с изучения готовой структуры, а не с её создания.

## Задание

1. Изучите структуру `webapp` командами `find` и `ls -la`. Убедитесь, что в ней есть каталоги `src`, `config`, `tmp`, `data` и файлы внутри них.
2. С помощью `find` найдите и удалите только временные файлы с расширениями `.tmp` и `.cache` внутри `tmp`.
3. Создайте архив проекта в формате `tar.gz`, но исключите из него `tmp` и файл с секретами `config/.env`.
4. Имя архива должно содержать текущую дату, полученную командой, а не вписанную вручную.
5. Выведите список содержимого архива без распаковки.
6. Проверьте архив распаковкой в отдельный каталог `restore`, затем сравните дерево файлов с исходным проектом. Не допускайте попадания секретов и временных файлов в архив.

## Ограничения

- Нельзя использовать графический файловый менеджер.
- Нельзя удалять весь каталог проекта целиком.
- Перед удалением проверьте список найденных файлов отдельной командой.
- Для проверки архива используйте `tar -tzf`, `tar -xzf`, `find`, `diff` или эквивалентные команды.

## Подсказки

Вам пригодятся: `mkdir -p`, `printf`, `find`, `rm`, `date`, `tar`, `--exclude`, `sort`, `diff`, `test` и условные конструкции shell.

В папке уже подготовлены исходные данные:

- `webapp/src/index.html` и `webapp/src/app.js` — исходный код;
- `webapp/config/app.conf` — обычная конфигурация;
- `webapp/config/.env` — секретный файл, который нельзя включать в архив;
- `webapp/data/users.csv` — учебные данные;
- `webapp/tmp/cache.tmp` и `webapp/tmp/session.cache` — временные файлы для удаления.

Архив в папке заранее не лежит: его нужно создать самостоятельно в рамках задания. Это позволяет потренироваться в формировании имени, исключении файлов и проверке восстановления.

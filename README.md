# Практикум: 5 заданий по Linux-терминалу

Задания расположены по возрастанию сложности:

1. `01_навигация_и_файлы` — каталоги, файлы, просмотр, копирование, перемещение и удаление.
2. `02_права_и_поиск` — права доступа, `chmod`, `find`, `grep`, перенаправление и статистика.
3. `03_конвейеры_и_обработка` — конвейеры, `awk`, сортировка, подсчёт частот и скрипт. Высокоуровневые приёмы отмечены ⭐.
4. `04_резервное_копирование` — самостоятельное проектирование архивации и проверки восстановления.
5. `05_анализ_журналов` — самостоятельное расследование по журналу авторизации.

В каждом каталоге есть `readme.md` с условиями, а `task.md` содержит сценарий задания. Первые три `readme.md` включают решения; в последних двух решений нет.

Работайте только внутри папки текущего задания. Перед командами `rm`, `mv` и перенаправлением `>` проверяйте путь и имя файла.

# Практическая работа: Базовые команды командной оболочки Linux (Bash)

## Инструкция по выполнению

- Все исходные данные для заданий находятся в каталогах `data/` и `project/`.
- Каждое задание решается с помощью стандартных утилит командной строки Linux (`grep`, `wc`, `sort`, `uniq`, `cut`, `find`, конвейеров `|` и др.).
- В качестве ответа на каждое задание требуется предоставить **строго одно значение** (конкретное число или конкретную текстовую строку без лишних пробелов, кавычек или пояснений).
- Объем данных увеличен до десятков тысяч записей, поэтому выполнение заданий вручную («глазами») исключено — требуется составить корректный конвейер команд.

---

### Задание 1. Анализ логов веб-сервера (поиск и подсчёт)
* **Файл:** `data/server.log`
* **Описание:** Файл журнала веб-сервера (35 000 строк). Каждая запись содержит информацию об IP-клиента, времени, HTTP-методе, пути запроса, коде ответа HTTP и размере ответа.
* **Задача:** Подсчитайте общее количество запросов, которые завершились ошибкой с кодом статуса `404` (Not Found).
* **Формат ответа:** Целое число.

---

### Задание 2. Анализ активности пользователей (частотный анализ)
* **Файл:** `data/logins.txt`
* **Описание:** Файл содержит журнал авторизаций (25 000 строк), где каждая строка представляет собой логин пользователя.
* **Задача:** Определите логин пользователя, который входил в систему чаще всех остальных.
* **Формат ответа:** Строка (только логин пользователя).

---

### Задание 3. Обработка структурированных табличных данных (фильтрация и сортировка)
* **Файл:** `data/products.csv`
* **Описание:** Каталог товаров в формате CSV (10 000 позиций). Первая строка — заголовок со столбцами: `SKU,Name,Category,Price`.
* **Задача:** Найдите товар с максимальной стоимостью (`Price`) и определите его артикул (значение столбца `SKU`).
* **Формат ответа:** Строка (только значение артикула, например: `SKU-XXXXX`).

---

### Задание 4. Поиск в структуре каталогов и подсчёт файлов
* **Каталог:** `project/`
* **Описание:** Дерево каталогов и файлов проекта (~330 файлов различного типа, распределённых по разным уровням вложенности).
* **Задача:** Посчитайте, сколько обычных файлов с расширением `.conf` (имя файла строго оканчивается на `.conf`) находится внутри каталога `project/` и всех его подкаталогов любой глубины вложенности.
* **Формат ответа:** Целое число.

---

### Задание 5. Анализ журнала безопасности (уникальные значения)
* **Файл:** `data/auth.log`
* **Описание:** Файл журнала аутентификации OpenSSH (18 000 строк), фиксирующий попытки входа в систему.
* **Задача:** Подсчитайте количество **уникальных** IP-адресов, с которых были зафиксированы неудачные попытки входа (строки, содержащие фрагмент `Failed password`).
* **Формат ответа:** Целое число.

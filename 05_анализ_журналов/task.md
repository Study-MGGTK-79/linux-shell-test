# Практическая задача

Вы — дежурный специалист по безопасности. В 09:30 система обнаружила подозрительную активность, и вам передали журнал авторизации. Необходимо восстановить картину событий, отделить обычные ошибки пользователей от автоматизированной атаки и подготовить краткий отчёт для старшего администратора.

Хороший отчёт должен содержать конкретные факты, команды-проверки и осторожный вывод: по одному совпадению нельзя уверенно утверждать, что аккаунт взломан.

# Практическая задача

На сервере появились публичная страница, закрытый файл с настройками и журнал приложения. Подготовьте каталог с корректными правами, чтобы секреты не читали другие пользователи, публичная страница оставалась доступной для чтения, а журнал можно было найти и проанализировать.

Итоговый отчёт сохраните в `report.txt` внутри каталога задания.

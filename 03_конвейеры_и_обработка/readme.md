# Задание 3. Конвейеры и обработка текста

## Цель

Научиться соединять команды через конвейер, фильтровать, сортировать и агрегировать текстовые данные. Это задание завершает базовый блок и знакомит с более высокоуровневыми приёмами.

## Условия

Работайте с файлом `access.log` из этой папки.

1. Посчитайте общее число запросов.
2. Выведите только запросы с кодом `404` и только запросы метода `POST`.
3. Получите список IP-адресов без повторов и посчитайте, сколько запросов сделал каждый IP.
4. Определите самый часто встречающийся HTTP-код.
5. Найдите пять самых больших ответов по размеру.
6. Сформируйте `report.txt`, в котором есть: число строк, число ошибок `4xx/5xx`, топ-3 IP и топ-3 URL.
7. Повторите хотя бы одну часть решения в виде небольшого скрипта `make_report.sh`.

## Решение

```bash
# Посмотреть исходные строки
head access.log

# 1. Число запросов
wc -l < access.log

# 2. Фильтрация строк
grep ' 404 ' access.log
grep '"POST ' access.log

# 3. IP без повторов и число запросов каждого IP
awk '{print $1}' access.log | sort -u
awk '{print $1}' access.log | sort | uniq -c | sort -nr

# 4. Самый частый HTTP-код (в формате Combined Log код находится в 9-м поле)
awk '{print $9}' access.log | sort | uniq -c | sort -nr | head -n 1

# 5. Пять самых больших ответов (размер — 10-е поле)
sort -k10,10nr access.log | head -n 5

# 6. Отчёт с несколькими конвейерами и подстановками команд
{
  printf 'Всего запросов: '
  wc -l < access.log
  printf 'Ошибок 4xx/5xx: '
  awk '$9 ~ /^[45][0-9][0-9]$/ {n++} END {print n+0}' access.log
  printf '\nТоп-3 IP:\n'
  awk '{print $1}' access.log | sort | uniq -c | sort -nr | head -n 3
  printf '\nТоп-3 URL:\n'
  awk '{print $7}' access.log | sort | uniq -c | sort -nr | head -n 3
} > report.txt
cat report.txt

# 7. Скрипт с аргументом: запускать как ./make_report.sh access.log
cat > make_report.sh <<'SCRIPT'
#!/usr/bin/env bash
set -euo pipefail
log="${1:?Укажите путь к журналу}"
{
  echo "Всего: $(wc -l < "$log")"
  echo "Ошибки: $(awk '$9 ~ /^[45][0-9][0-9]$/ {n++} END {print n+0}' "$log")"
  echo 'Топ IP:'
  awk '{print $1}' "$log" | sort | uniq -c | sort -nr | head -n 3
} > report-from-script.txt
SCRIPT
chmod +x make_report.sh
./make_report.sh access.log
```

## Звёздочка: высокоуровневые приёмы

⭐ **Конвейер** `|` передаёт вывод одной команды на вход другой.

⭐ **`awk`** умеет разбирать строки на поля и выполнять условия, например `$9 ~ /^[45]/`.

⭐ **`sort | uniq -c | sort -nr`** — универсальный шаблон подсчёта частот.

⭐ **`{ ...; } > file`** позволяет собрать вывод нескольких команд в один отчёт.

⭐ **Here-document** `<<'SCRIPT'` удобен для создания многострочного скрипта прямо из терминала.

> В учебных целях здесь используется `cat > make_report.sh`. В обычной работе проверяйте путь перед перенаправлением: `>` перезапишет существующий файл.
